# SEO Spacing Rules

Базовые правила по отступам для страниц сайта SEO (чтобы не было разнобоя):

- Между крупными секциями: `64px` (desktop), `48px` (tablet), `32px` (mobile).
- Внутри текстового блока: от заголовка до текста `20px` (desktop), `12px` (mobile).
- Отступы внутри карточек: `20px` со всех сторон (desktop), допустимо `14-16px` на mobile.
- Для блоков с фоном (pricing/tech/form): использовать одинаковый вертикальный ритм секций.
- Для чекбокс-лейблов: всегда явный пробел перед ссылкой на политику.

Токены вынесены в: `src/shared/styles/spacing-system.scss`.
